# CodeAlpha Student Grade Tracker

A console-based Java project for managing student scores and generating a summary report.

## Features
- Accepts the number of students, names, and scores.
- Stores student records in an `ArrayList`.
- Calculates average, highest, and lowest scores.
- Assigns a letter grade based on the score.
- Validates student count and score input.
- Displays a formatted summary report.

## Requirements
- Java JDK 8 or later
- Terminal / command prompt

## Run
1. Open a terminal in this folder.
2. Compile:
   ```bash
   javac StudentGradeTracker.java
   ```
3. Run:
   ```bash
   java StudentGradeTracker
   ```

## Grade scale used
- 90–100: A+
- 80–89.99: A
- 70–79.99: B
- 60–69.99: C
- 50–59.99: D
- Below 50: F

This grading scale is a project choice and can be changed if the task instructions specify a different scale.
